# Synhub — Enterprise Project & Task Management System

**Synhub** is a full-stack task and project management web application featuring:
1. **Interactive Project Kanban Board**: Task tracking across status columns with assigned editing restrictions.
2. **Employee Dashboard**: "My Day" daily focus list, personal task management, and recurring schedule processing.
3. **Manager Dashboard**: Executive team workload metrics, progress breakdown, task error/blocker quality control, and AI status summaries.
4. **Read-Only Project Status Overview**: High-level milestone metrics and project completion statistics accessible to team members.
5. **AI Assistant**: Natural text copilot for task queries, next task recommendations, and plain-text task execution.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm run install:all
```

### 2. Run Application
```bash
npm run dev
```

Open your browser at **`http://localhost:3000`**.
